# 📘 Phrasal Verbs (Cheat Sheet)

A **phrasal verb** is a verb + a small word (a **particle**) that together create a **new meaning**. The meaning is often different from the separate words:

*get* + *over* → **get over** = recover from

## 1. What is a Phrasal Verb?
Think of each phrasal verb as **one new word** and learn it with its meaning.

- **pick up** = lift / collect
- **give up** = quit
- **work out** = exercise (or: solve, succeed)

⚠️ One base verb can make many phrasal verbs with different meanings: *get up, get over, get along with, get away with.*

**Phrasal verb vs idiom:**
- **Phrasal verb** = verb + particle → *give up* (stop trying)
- **Idiom** = a fixed expression whose words don't explain the meaning → *spill the beans* (reveal a secret)

## 2. Structure
`Verb + Particle` *(the particle is an adverb or a preposition)*

- **get up**
- **work out**
- **pick up**

`Verb + Particle + Preposition` *(3 words — see [section 6](#6-phrasal-verbs-with-3-words))*

- **look up to**
- **get along with**

## 3. Verb Changes
✅ Only the **verb** changes — the particle stays the same.

| Form | Example |
| :--- | :--- |
| Base | I **work out** every day. |
| He / she / it | He **works out** every day. |
| Past | He **worked out** yesterday. |
| -ing | He is **working out** right now. |
| Present perfect | He has **worked out** three times this week. |
| Infinitive | I want **to work out**. |
| Gerund | **Working out** is good for you. |

Irregular verbs use their own forms: *get up → got up → has got up (US: gotten up).*

## 4. Types
Phrasal verbs are sorted by **two questions**. Each verb is exactly one type from each pair.

| Question | Type | Meaning | Example |
| :--- | :--- | :--- | :--- |
| **Is there an object?** | **Transitive** | has an object | She **turned down** the offer. |
| | **Intransitive** | no object | The car **broke down**. |
| **Can it be split?** | **Separable** | the object can go in the middle | She **called** the party **off**. |
| | **Inseparable** | never split | She **looks after** her sister. |

**Link between the pairs:**
- All **intransitive** phrasal verbs are **inseparable** (no object, nothing to split).
- All **separable** phrasal verbs are **transitive**.
- Some transitive phrasal verbs are **inseparable** too.

⚠️ Some phrasal verbs have **more than one meaning**, and the type can change with the meaning:
- **give up** = quit → no object: *Don't **give up**.*
- **give up** = stop doing something → object: *He **gave up** chocolate.* / *He **gave** chocolate **up**.*

## 5. Word Order

| Type | Rule | Example |
| :--- | :--- | :--- |
| **Intransitive** | no object | The meeting **went on** for hours. |
| **Inseparable** | object goes **after** the particle | I **count on** my friends. / I **count on** them. |
| **Separable** + noun | object in the **middle or at the end** | **Call off** the meeting. / **Call** the meeting **off**. |
| **Separable** + pronoun | pronoun **must** go in the **middle** | **Call it off**. ✅ ❌ ~~Call off it~~ |

**More examples:**
- He is **picking up** the litter. → He is **picking** the litter **up**.
- Pick **it** up. ✅ ❌ ~~Pick up it~~

💡 **Quick test:** put **it** between the verb and the particle.
- **pick it up** sounds right → **separable**
- ~~look it after~~ sounds wrong → **inseparable** (*look after it*)

⚠️ With some separable verbs the middle position is the normal one, e.g. **let me know**.
⚠️ There is no rule that tells you which verbs are separable — learn each one with an example sentence.

## 6. Phrasal Verbs with 3 Words
Verb + particle + preposition. They are **always inseparable** — the object (even *it* or *them*) goes **after** all the words.

| Phrasal verb | Meaning | Example |
| :--- | :--- | :--- |
| **look up to** | admire | He **looks up to** his brother. |
| **get along with** | have a good relationship with | She **gets along with** her colleagues. |
| **put up with** | tolerate | I can't **put up with** this noise. |
| **run out of** | use all of something | We **ran out of** milk. |
| **come up with** | think of (an idea) | She **came up with** a great plan. |
| **get away with** | do wrong without punishment | He **got away with** it. |
| **look forward to** | wait for happily | I **look forward to** meeting you. |

❌ I can't put **it** up with. → ✅ I can't **put up with it**.

## 7. Common Phrasal Verbs

### Separable — the object can go in the middle

| Phrasal verb | Meaning | Example |
| :--- | :--- | :--- |
| **back [x] up** | support | My team always **backs** me **up**. |
| **call [x] off** | cancel | They **called** the trip **off**. |
| **cheer [x] up** | make happier | That song **cheered** her **up**. |
| **give [x] away** | give for free | I **gave** my old books **away**. |
| **let [x] down** | disappoint | Don't **let** me **down**. |
| **let [x] in** | allow to enter | **Let** the dog **in**. |
| **pick [x] up** | lift / collect | I'll **pick** you **up** at eight. |
| **put [x] on** | wear | **Put** your coat **on**. |
| **set [x] up** | arrange / organize | We **set** the meeting **up**. |
| **take [x] out** | remove / bring outside | **Take** the trash **out**. |
| **throw [x] away** | discard | Don't **throw** it **away**. |
| **turn [x] down** | reject | He **turned** the job **down**. |
| **think [x] over** | consider carefully | **Think** it **over**. |

### Inseparable — the object comes after

| Phrasal verb | Meaning | Example |
| :--- | :--- | :--- |
| **look after** | take care of | She **looks after** her sister. |
| **get over** | recover from | He **got over** the flu quickly. |
| **count on** | rely on | You can **count on** me. |
| **go over** | review | Let's **go over** the notes. |
| **take after** | resemble (a family member) | She **takes after** her mother. |
| **get through** | finish / survive | I can't **get through** the day without coffee. |
| **go against** | oppose / disobey | He **went against** the rules. |

### Intransitive — no object

| Phrasal verb | Meaning | Example |
| :--- | :--- | :--- |
| **break down** | stop working | The elevator **broke down**. |
| **calm down** | relax | Please **calm down**. |
| **get up** | leave your bed | I **get up** at 6 AM. |
| **go ahead** | proceed | Please **go ahead**. |
| **show off** | display skills to impress | He is just **showing off**. |
| **end up** | finally reach a result | We **ended up** staying home. |
| **get by** | manage with little | They **get by** on one salary. |
| **get together** | meet socially | Let's **get together** on Friday. |

## 8. Quick Tips
- ✅ Only the **verb** changes (*gets up, got up, getting up*); the particle never changes.
- **Separable + pronoun** → pronoun goes **in the middle**: *call **it** off.*
- **3-word phrasal verbs** → never split: *put up with **it**.*
- A verb after a phrasal verb takes **-ing**: *give up **smoking**, end up **staying**, look forward to **meeting**.*
- Check the **meaning** from context — one phrasal verb can have several meanings (*get down, give up, work out*).
- Learn phrasal verbs **in sentences**, not as isolated words.
