---

**Meaning:** to say that something **exists** (or doesn't exist).

**Key:** `be verb` · *noun* · **there** / **how many** · <ins>time expression</ins>

---

## 1. Affirmative

| Structure | Example |
| :--- | :--- |
| **There** `is` + *singular noun* | **There** `is` a *book* on the desk. |
| **There** `are` + *plural noun* | **There** `are` *books* on the desk. |
| **There** `is` + *uncountable noun* | **There** `is` some *milk* in the fridge. |

---

## 2. Negative

| Structure | Example |
| :--- | :--- |
| **There** `isn't` + *singular noun* | **There** `isn't` a *pen* on the table. |
| **There** `aren't` + *plural noun* | **There** `aren't` any *pens* here. |
| **There** `isn't` + *uncountable noun* | **There** `isn't` any *juice* in the fridge. |

---

## 3. Questions

To make a question, **swap** the places of **there** and the `be verb`.

| Statement | Question |
| :--- | :--- |
| **There** `is` a *cat* on the chair. | `Is` **there** a *cat* on the chair`?` |
| **There** `are` *cats* on the sofa. | `Are` **there** *cats* on the sofa`?` |

```text
  There    is     a cat on the chair.
```

## 4. Asking About Quantity

To ask **how many** things exist, use:

**How many** + *plural noun* + `are` **there** ...?

- **How many** *students* `are` **there** in your class?
- **How many** *days* `are` **there** in February?

---

## 5. There Was / There Were (Past)

- **There** `is` a *train* <ins>every hour</ins>.
- The time now is 11.15. **There** `was` a *train* <ins>at 11 o'clock</ins>.

**Compare** there is / there are (present) and there was / there were (past):

| Present | Past |
| :--- | :--- |
| **There** `is` a good *film* on TV <ins>tonight</ins>. | **There** `was` a good *film* on TV <ins>last night</ins>. |
| We are staying at a very big hotel. **There** `are` 550 *rooms*. | We stayed at a very big hotel. **There** `were` 550 *rooms*. |
| `Are` **there** any phone *messages* for me <ins>this morning</ins>? | `Were` **there** any phone *messages* for me <ins>yesterday</ins>? |
| I'm hungry, but **there** `isn't` anything to eat. | I was hungry when I got home, but **there** `wasn't` anything to eat. |

---

## 6. There Has Been / There Have Been (Present Perfect)

- Look! **There**`'s been` an *accident*. (**there**`'s been` = **there** `has been`)
- This road is very dangerous. **There** `have been` many *accidents*.

**Compare** there was (past):

- ✅ **There** `was` an *accident* <ins>last night</ins>.
- ❌ **There** `has been` an *accident* <ins>last night</ins>.

---

## 7. There Will Be (Future)

- Do you think **there** `will be` a lot of *people* at the party <ins>on Saturday</ins>?
- The manager of the company is leaving, so **there** `will be` a new *manager* <ins>soon</ins>.
- I'm going away <ins>tomorrow</ins>. I'll do my packing <ins>today</ins> because **there** `won't be` *time* <ins>tomorrow</ins>. (**there** `won't be` = **there** `will not be`)

---

## 8. Contractions

| Short form | Full form |
| :--- | :--- |
| There's | There is |
| There's not | There is not |
| There isn't | There is not |
| There aren't | There are not |
| There's been | There has been |
| There won't be | There will not be |
