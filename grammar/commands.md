# 📘 Commands and Requests (Imperative Sentences)

> **What does "imperative" mean?** <br>
> It is the grammar word for a sentence that **tells someone to do something**. It comes from the Latin *imperare* = "to command" (same root as *emperor*). An **imperative sentence** is a command, request, instruction, piece of advice or warning.

## 1. What is an Imperative Sentence?
A sentence that **directly tells the listener what to do**. Use it for:

| Use | Example |
| :--- | :--- |
| **Commands** | **Close** the door. |
| **Instructions** | **Press** the button. |
| **Requests** | Please **pass** the salt. |
| **Advice** | **Take** a break. |
| **Offers / invitations** | **Have** a seat. |
| **Warnings** | **Be** careful! |

## 2. Form
`Base verb + rest of the sentence` — **no subject**.

- **Close** the door.
- **Tell** me the truth.
- **Wait** here.

**Rules:**
- The verb is in its **base form** (no *-s*, no *-ing*, no *to*).
- The subject is **you**, but it is *understood* — you don't say it: *(You)* Close the door.
- The form is the same for one person or many people.
- One word can be a full sentence: **Go.** / **Stop!** / **Run!**
- With *be*, use **be**: ✅ **Be** quiet. ❌ ~~Are quiet.~~
- You can add a name to say who you are talking to: **Tom**, come here. / **Everyone**, listen.

**Punctuation:** end with a period (.) — or an exclamation mark (!) if it is urgent or strong: *Get out!*

## 3. Negative
Tell someone **not** to do something.

| Pattern | Example |
| :--- | :--- |
| **Don't** + base verb | **Don't** run. |
| **Do not** + base verb *(formal, signs)* | **Do not** enter. |
| **Never** + base verb | **Never** give up. |

## 4. Conditional
A command that depends on a condition — it has **two parts**: *if / when* + clause, then the command.

- **If** you feel sick, **stay** home.
- **When** you arrive, **call** me.

## 5. Let's
`Let's` + base verb = a **suggestion that includes yourself** (*let us*).

- **Let's go.**
- Negative: **Let's not** argue.

## 6. Making It Polite
A plain imperative can sound **bossy**, especially with strangers or in writing. Make it softer:

| Level | Example |
| :--- | :--- |
| Direct | Close the door. |
| Softer | **Please** close the door. / Close the door, **please**. |
| Softest | **Could you** close the door, please? |

⚠️ A request in question form ends with a **question mark** (?).

## 7. Imperative or Not?
The meaning can be the same, but only the first one is an **imperative sentence**:

| Type | Example | Why |
| :--- | :--- | :--- |
| **Imperative** | Put your phone away. | base verb, no subject, direct command |
| Declarative | You need to put your phone away. | a statement with a subject |
| Interrogative | Can you put your phone away? | a question |

## 8. Quick Tips
- ✅ Start with the **base verb** — no subject.
- Negative = **Don't / Do not / Never** + base verb.
- Add **please** to sound polite.
- Use **Let's** to include yourself.
- Add a tag after a command to soften it: *Close the door, **will you**?* (see [Tag Questions](tag-questions.md))
